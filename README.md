# Mental Health Chatbot

A simple AI-powered Mental Health Chatbot designed to provide supportive conversations, emotional guidance, and basic wellness assistance through natural language interaction.

> ⚠️ This project is **not a replacement for professional therapy or medical help**. It is intended for educational and supportive purposes only.

---

## ✨ Features

* 💬 Interactive chatbot conversation
* 😊 Emotion-aware responses
* 🧘 Mental wellness suggestions
* 🔒 User-friendly and simple interface
* ⚡ Fast response system
* 🌙 Clean and minimal UI

## 🚀 Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/CodeCrafter-101/mental-health-chatbot.git
cd mental-health-chatbot
```

### 2️⃣ Create Virtual Environment

```bash
python -m venv venv
```

### 3️⃣ Activate Virtual Environment

#### Windows

```bash
venv\Scripts\activate
```

#### Mac/Linux

```bash
source venv/bin/activate
```

### 4️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 5️⃣ Run the Application

```bash
python app.py
```

## 📸 Screenshots

### 💬 Stress & Overthinking Support
The chatbot responding to a user dealing with stress, overthinking, and sleep issues by providing calming advice and coping suggestions.

User: Hi, I have been feeling very stressed lately. I keep overthinking every small thing and can't sleep properly.

Bot: I'm so sorry to hear you're going through this. It sounds like you're feeling overwhelmed by your thoughts. Have you considered trying journaling to process and release some of that stress? Writing down your thoughts can sometimes help you gain clarity and perspective.

User: How do I manage it?

Bot: Try taking things one step at a time instead of focusing on everything at once. Deep breathing exercises, limiting screen time before sleep, maintaining a healthy routine, and talking to someone you trust can also help reduce stress and overthinking. Remember to give yourself proper rest and be patient with yourself.

### 🧠 Emotional Support Conversation
Example of the chatbot giving supportive guidance and wellness tips during an emotional conversation.

User: I have been feeling emotionally drained and unmotivated lately.

Bot: It sounds like you're carrying a heavy emotional burden right now. That can be really tough to navigate. Have you considered taking a step back from your daily routine to prioritize self-care? Perhaps try a relaxing activity like meditation, a warm bath, or reading a book with no expectations.

Bot: Can you tell me more about what's been weighing on your mind?

User: Sometimes I feel like I'm not doing enough in life.

Bot: It's understandable to feel uncertain about whether we're meeting our own expectations. Sometimes, this can stem from comparing ourselves to others or having an idealized vision of success. Have you considered breaking down your goals into smaller, achievable milestones? This can help you focus on progress rather than perfection.
